# Hickey POS — installers

This repository only holds the **Windows installers** of Hickey POS, published by the release workflow of the
(private) source repository. Installed counters check its releases for updates and install them by themselves.

Nothing to do here by hand: new versions appear under **Releases** when a version is tagged in the source repo.
To install a counter from scratch, download the newest `Hickey-POS-Setup-x.y.z.exe` from
[Releases → latest](https://github.com/tharunkuchulu/hickey-releases/releases/latest).
